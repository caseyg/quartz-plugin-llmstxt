# quartz-plugin-llmstxt

A [Quartz](https://quartz.jzhao.xyz) emitter plugin that generates [`/llms.txt`](https://llmstxt.org), `/llms-full.txt`, and `.md` mirrors of every page — so AI agents can discover and consume your site's content without parsing HTML.

Follows the [llms.txt v2 specification](https://llmstxt.org).

## What it emits

| File             | Description                                                                                                                |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `/llms.txt`      | Curated index: H1 title, blockquote description, pages grouped by folder into H2 sections, links pointing to `.md` mirrors |
| `/llms-full.txt` | All page source markdown concatenated (opt-out with `emitFullTxt: false`)                                                  |
| `/<slug>.md`     | Raw source markdown for every published page (opt-out with `emitMarkdownMirrors: false`)                                   |

## Installation

```sh
npx quartz plugin add github:caseyg/quartz-plugin-llmstxt
```

Then register it in `quartz.config.yaml`:

```yaml
plugins:
  - source: "github:caseyg/quartz-plugin-llmstxt"
    enabled: true
```

## Options

| Option                | Type                     | Default | Description                                                                              |
| --------------------- | ------------------------ | ------- | ---------------------------------------------------------------------------------------- |
| `emitMarkdownMirrors` | `boolean`                | `true`  | Emit `<slug>.md` for every published page                                                |
| `emitFullTxt`         | `boolean`                | `true`  | Emit `/llms-full.txt`                                                                    |
| `sections`            | `Record<string, string>` | `{}`    | Map folder prefixes to custom H2 section names (e.g. `{ "notes": "My Notes" }`)          |
| `optionalPrefixes`    | `string[]`               | `[]`    | Slug prefixes routed to `## Optional` in `llms.txt`                                      |
| `excludeFromIndex`    | `string[]`               | `[]`    | Slug prefixes excluded from `llms.txt` and `llms-full.txt` (`.md` mirrors still emitted) |
| `description`         | `string`                 | `""`    | Override the blockquote description in `llms.txt` (defaults to site title)               |

## How it works

### `llms.txt` structure

Pages are automatically grouped into sections by their top-level folder:

- `notes/my-page` → `## Notes`
- `projects/thing` → `## Projects`
- `about` (root-level) → `## Pages`

Sections are sorted alphabetically, with `## Optional` always last. Custom section names and optional/excluded prefixes are configured via options.

All links in `llms.txt` point to the `.md` mirror URL (e.g. `https://example.com/notes/my-page.md`), not the HTML page.

### `.md` mirrors

Each mirror is the raw source markdown read directly from the original file on disk — faithful to what you wrote, including frontmatter. Virtual pages (generated by Quartz with no source file) are skipped silently.

### `llms-full.txt`

A single file containing all page source markdown, separated by `---` dividers with headings identifying each page. Useful for agents that want everything in one context load.

## Known limitations

- No `<link rel="alternate" type="text/markdown">` injection into page `<head>` tags. Agents that start from `llms.txt` don't need this, but browser-based agents navigating individual pages won't auto-discover the markdown version.
